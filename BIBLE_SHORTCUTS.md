# Bible Shortcuts and Translations

This document provides a reference for the Bible version abbreviations and book shortcuts supported by the ECC Prayer Bot.

## Supported Bible Versions

You can specify a version by adding its abbreviation (e.g., `John 3:16 KJV`). If no version is specified, the default version (KJV) will be used.

### Standard Versions
- **KJV**: King James Version
- **ASV**: American Standard Version
- **WEB**: World English Bible
- **BBE**: Bible in Basic English
- **WEBBE**: World English Bible British Edition

### Premium Versions
- **NIV**: New International Version
- **NKJV**: New King James Version
- **NLT**: New Living Translation
- **AMP**: Amplified Bible
- **MSG**: The Message
